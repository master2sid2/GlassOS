# ui — widgets

Widgets only work inside `app.ui`. Outside it they draw nothing and return the value they were given, or `false`.

## The principle

A widget gets the current value and returns the new one. The program keeps the value:

```lua
state.name = ui.input("name", state.name, "Your name")
```

Widgets are laid out top to bottom. Fields take the whole available width. `id` is a string unique within the window: the system recognises the widget between frames by it.

## Layout

### ui.sameline()

The next widget goes to the right of the previous one.

```lua
ui.label("Name", 0x8A90A8, 110)
ui.sameline()
state.name = ui.input("name", state.name)
```

### ui.space([height])

Vertical space, 10 pixels by default.

### ui.separator()

A horizontal line.

## Text

### ui.heading(text)

A heading, 18 pixels.

### ui.label(text [, color [, width]])

A line of text. `width` sets the minimum width: this is how a column of labels is aligned. Lines are not wrapped.

### ui.panel(text [, color [, height]])

A coloured plate with centred text, 44 high by default. The text colour is picked to match the background automatically.

## Controls

### ui.button(label) → clicked

Returns `true` in the frame when the button was pressed.

### ui.checkbox(label, value) → value

A checkbox; `value` is a boolean.

### ui.radio(options, selected) → selected

Radio buttons: `options` is an array of strings, `selected` the selected string.

```lua
state.size = ui.radio({ "Small", "Medium", "Large" }, state.size)
```

### ui.dropdown(id, options, selected) → selected

A dropdown list, up to 260 wide. An empty `selected` shows as `Select...`.

### ui.slider(id, value, min, max) → value

A slider with integer values, 0–100 by default.

### ui.color(value) → value

A palette of 10 colours. Returns the chosen colour `0xRRGGBB`.

### ui.tabs(id, items, selected) → selected

"Pill" tabs. The program draws the tab contents itself:

```lua
state.tab = ui.tabs("main", { "General", "About" }, state.tab)
if state.tab == "General" then
  ui.label("Settings go here")
end
```

### ui.list(id, items, selected [, height]) → selected

A list of strings, 160 high by default. `selected` is the row number from 1, `0` means nothing is selected. If the rows do not fit, a scroll bar appears on the right. The list scrolls with the mouse wheel over it or by dragging the thumb. When the program changes `selected` itself, for example moves to the next song, the list scrolls to that row. `id` tells lists apart: each has its own scroll position.

The wheel over the rest of the window scrolls the window if its contents are taller than it; then a thin bar is visible on the right.

### ui.progress(value [, max])

A progress bar, `max` is 100 by default.

## Text input

### ui.input(id, text [, placeholder]) → text

A single-line field, up to 200 characters. Supports a cursor anywhere in the line, selection with the mouse and with Shift, double-click on a word, Ctrl+A/C/X/V, Home/End, moving by words with Ctrl.

Enter and Esc remove the focus. **The field does not report Enter**: use a button to submit a form.

### ui.textarea(id, text [, height]) → text

A multi-line field, up to 4000 characters, 120 high by default. Enter — a new line, Esc — remove the focus, Ctrl+V — paste. The cursor is only at the end of the text, there is no selection. The last lines that fit are shown.

Both fields accept text in any enabled input language: `ui.input` and `ui.textarea` return it in UTF-8.

## Drawing

### ui.image(data, width [, height]) → clicked

A picture: `data` is the bytes of a PNG, JPEG, GIF or BMP file (for example, `fs.read(path)` or `audio.cover(id)`). It is fitted into `width`×`height` (the height equals the width by default) preserving proportions, centred. A width larger than the available one is reduced to it. The decoded picture is remembered, so it can be passed in every frame. If the data is not a picture, an empty frame is drawn.

### ui.canvas(height, draw) → clicked, x, y, held

An area for your own graphics: see [gfx — drawing](03-gfx.md).
